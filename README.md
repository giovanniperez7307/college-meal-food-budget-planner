# college-meal-food-budget-planner
A budget planner to help students manage their spending on meals.
# College Meal & Food Budget Planner

**COSC 1302 — Introduction to Computer Science**

**Created by:** Gio, A.J., and Jay

#Description


The program allows users to set a weekly food budget, add and remove grocery items, calculate total spending, view their remaining budget, sort grocery items by price, and receive affordable meal recommendations.

## Project Objectives

- Track grocery expenses.
- Calculate remaining weekly budget.
- Organize grocery items.
- Sort grocery prices using Bubble Sort.
- Recommend affordable meals using a Greedy Selection algorithm.

## Technologies

- Python 3
- Google Colab
- GitHub

## Main Features

1. Set a weekly food budget.
2. View a grocery product catalog.
3. Add and remove grocery items.
4. Calculate total grocery spending.
5. Display remaining budget.
6. Sort grocery items from cheapest to most expensive.
7. Recommend affordable meals.
8. Create and view a weekly meal plan.
9. Display spending by category.

## Algorithms


### Meal Selection

The Greedy Selection algorithm sorts sample meals by estimated cost and selects the cheapest meals that fit within the available meal budget.

This method is a heuristic and does not guarantee the best overall meal plan for nutrition or variety.

## Project Limitations

- Grocery prices are sample estimates.
- The program does not connect to live grocery store prices.
- The program does not provide nutritional or allergy analysis.
- The Selection algorithm does not guarantee an optimal meal plan.
